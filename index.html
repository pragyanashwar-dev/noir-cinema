Storage & TV setup

Current mode: Local browser library

This starter app saves uploaded videos in IndexedDB on the device where you upload them. For the same library to appear on your phone and Smart TV, it must be connected to a cloud storage service and deployed to a web address accessible by both devices.

Cloud sync is not configured in this standalone starter. A secure cloud version needs a storage provider, sign-in, access rules and a hosted app. Do not put private service-role keys in browser code.

Open the hosted app's web address in your Smart TV browser and sign in. This local-only version will not transfer files between devices automatically. Some TV browsers may not support every video codec; MP4 with H.264/AAC is the safest general choice.
